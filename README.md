## AI-Powered Learning Platforms

- [LearnAI](https://uselearnai.com/chat) - AI tutor that generates personalized curricula and teaches through conversation. Covers Python, JavaScript, AI/ML, and more.
- [Khan Academy + Khanmigo](https://www.khanacademy.org/) - Khanmigo is Khan Academy's AI tutor built on GPT-4, offering guided problem-solving across subjects.
- [Brilliant](https://brilliant.org/) - Interactive STEM learning with AI-driven problem sequences that adapt to your level.
- [DataCamp](https://www.datacamp.com/) - AI-powered courses for data science, Python, R, and SQL with hands-on exercises.
- [Codecademy](https://www.codecademy.com/) - Interactive coding courses with AI features for personalized learning paths.

## AI Coding Assistants

- [GitHub Copilot](https://github.com/features/copilot) - AI pair programmer that suggests code as you type. Great for learning patterns.
- [Cursor](https://cursor.sh/) - AI-first code editor built for learning and building with AI assistance.
- [Codeium](https://codeium.com/) - Free AI code completion for 70+ languages.
- [Replit AI](https://replit.com/) - Browser-based IDE with AI that can explain, debug, and generate code.
- [Claude](https://claude.ai/) - Anthropic's AI that excels at explaining complex code and concepts.

## Learn Python

- [LearnAI for Python](https://uselearnai.com/chat?topic=python) - AI-powered personalized Python tutor with adaptive curriculum.
- [learn-python-with-ai](https://github.com/buildonlabs/learn-python-with-ai) - Free, structured Python learning roadmap with AI tutoring support.
- [Python.org Official Tutorial](https://docs.python.org/3/tutorial/) - The official Python tutorial, best paired with an AI assistant for Q&A.
- [Automate the Boring Stuff](https://automatetheboringstuff.com/) - Free book on practical Python for total beginners.
- [Real Python](https://realpython.com/) - In-depth Python tutorials and articles for all levels.
- [100 Days of Code: Python](https://www.udemy.com/course/100-days-of-code/) - Project-based Python bootcamp by Dr. Angela Yu.

## Learn JavaScript

- [LearnAI for JavaScript](https://uselearnai.com/chat?topic=js) - AI-powered personalized JavaScript tutor with adaptive curriculum.
- [learn-javascript-with-ai](https://github.com/buildonlabs-org/learn-javascript-with-ai) - Free, structured JavaScript learning roadmap with AI tutoring support.
- [javascript.info](https://javascript.info/) - Modern JavaScript tutorial from basics to advanced topics.
- [freeCodeCamp JavaScript](https://www.freecodecamp.org/learn/javascript-algorithms-and-data-structures/) - Free interactive JavaScript course with certifications.
- [Eloquent JavaScript](https://eloquentjavascript.net/) - Free book covering JavaScript fundamentals and beyond.
- [The Odin Project](https://www.theodinproject.com/) - Full-stack curriculum with a strong JavaScript track.

## Learn AI / ML / Deep Learning

- [LearnAI for Machine Learning](https://uselearnai.com/chat?topic=ml) - AI-powered personalized ML tutor with adaptive curriculum.
- [ai-ml-learning-roadmap](https://github.com/buildonlabs-org/ai-ml-learning-roadmap) - Structured roadmap with free resources and projects for learning AI/ML.
- [fast.ai](https://www.fast.ai/) - Practical deep learning courses — top-down approach, learn by doing.
- [Andrew Ng's Machine Learning (Coursera)](https://www.coursera.org/learn/machine-learning) - The most popular ML course ever created.
- [Google's Machine Learning Crash Course](https://developers.google.com/machine-learning/crash-course) - Free, fast-paced intro to ML by Google.
- [Hugging Face Course](https://huggingface.co/learn) - Free NLP and transformer courses with hands-on notebooks.
- [Stanford CS229](https://cs229.stanford.edu/) - Stanford's graduate ML course with free lectures and notes.
- [Papers With Code](https://paperswithcode.com/) - ML papers with linked code implementations.

## Learn LLMs & Prompt Engineering

- [Prompt Engineering Guide](https://www.promptingguide.ai/) - Comprehensive guide to prompt engineering techniques.
- [OpenAI Cookbook](https://cookbook.openai.com/) - Practical examples for working with the OpenAI API.
- [LLM University by Cohere](https://docs.cohere.com/docs/llmu) - Free course covering LLM fundamentals.
- [Anthropic's Claude Documentation](https://docs.anthropic.com/) - Best practices for building with Claude.
- [Microsoft Generative AI for Beginners](https://github.com/microsoft/generative-ai-for-beginners) - 18-lesson course on building generative AI apps.
- [LangChain Docs](https://docs.langchain.com/) - Framework for building LLM-powered applications.

## AI for Math & Science

- [Wolfram Alpha](https://www.wolframalpha.com/) - Computational intelligence for step-by-step math solutions.
- [Photomath](https://photomath.com/) - Scan math problems and get AI-powered step-by-step explanations.
- [Symbolab](https://www.symbolab.com/) - AI math solver with detailed solution steps.

## AI for Language Learning

- [Elsa Speak](https://elsaspeak.com/) - AI pronunciation coach for English learners.

## Interactive Coding Playgrounds

- [LeetCode](https://leetcode.com/) - Algorithm challenges with AI-powered hints and solution explanations.
