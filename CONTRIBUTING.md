# Contributing to Awesome AI Learning

Thank you for contributing! This list is community-driven and we welcome high-quality additions.

## Guidelines

- **Quality over quantity.** Only suggest resources you've personally used or that are widely recognized as excellent.
- **One resource per pull request.** This makes review easier.
- **Follow the format.** Use: `- [Name](URL) - Brief description ending with a period.`
- **Place in the correct category.** If unsure, suggest a category in your PR description.
- **No duplicates.** Search the list first.
- **No affiliate links.**
- **English language resources only** (for now).

## How to Contribute

1. Fork this repository
2. Add your resource to the appropriate section in `README.md`
3. Submit a pull request with a brief explanation of why the resource is awesome

## Updating Your PR

If changes are requested, push additional commits to the same branch. We'll squash on merge.

## Quality Criteria

Resources should meet at least one of:

- Widely used by the community (stars, reviews, recommendations)
- Created by recognized experts or institutions
- Offers something unique not covered by existing entries
- Free or has a substantial free tier

Thank you for making this list better!
